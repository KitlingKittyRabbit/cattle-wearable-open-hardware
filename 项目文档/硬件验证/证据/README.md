# Validation evidence

This directory is reserved for small, reviewable hardware-test evidence, such
as:

- a short SD-card data sample used to validate `工具/bin2csv.py`;
- a short NF-03 receiver log demonstrating a physical radio packet;
- a necessary screenshot or compact text summary.

No physical-test sample or receiver log is included in the initial public
release. Add evidence only after a manual hardware test, and record its source,
date, firmware commit, and intended use in the corresponding validation record.

Do not commit long experiments, complete SD-card exports, private farm or animal
data, or large radio logs. Every evidence file must have a clear provenance and
data-sharing permission.
